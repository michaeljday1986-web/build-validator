# Endpoint Handover Validator

A lightweight PowerShell WPF tool for validating newly built Windows endpoints before technician handover.

## Features

- Automated Windows endpoint checks
- TPM, BitLocker, Secure Boot and activation validation
- Endpoint protection detection
- Entra/domain join check
- Manual technician checklist
- Health score summary
- Copy summary for tickets
- HTML report export

## Built With

- PowerShell
- WPF/XAML
- Windows Management / CIM
